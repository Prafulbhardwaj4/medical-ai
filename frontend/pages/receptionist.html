No new token, no new fee. Use this when the doctor asked to see this patient again later today (e.g. after a test result) — same visit, same doctor.

A brand-new token with its own fee. Use this for a second, separate visit today — including seeing a different doctor (e.g. one for fever, another for a plaster). You'll get the same "Add Doctor" option on the next screen if they need more than one.
