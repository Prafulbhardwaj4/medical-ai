Rooms

Name/Number are both optional — fill whichever applies. Room Type controls which room shows up in the doctor's or nurse's room picker: only Doctor-type rooms appear for doctors, only Nurse-type for nurses. General/Other don't appear in either staff picker. Seq # is an optional shortcut number the receptionist can type at check-in to jump straight to this room — must be unique across active rooms. Emergency patients are no longer routed through Rooms — see Admissions → Manage Rooms & Ward Types for the Emergency Ward.
